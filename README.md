# 弈境 · 3D 五子棋

使用 **Three.js + Vite** 实现的浏览器五子棋小游戏。程序生成木纹棋盘，搭配立体棋子、棋罐、PBR 材质和灯光阴影；无需下载外部贴图。支持内置 AI、本机双人对弈、棋局保存，以及 OpenAI 兼容模型接口。

## 本地运行

需要 Node.js **22.12+**，推荐 Node.js 24，以及支持 WebGL 的现代浏览器。

```bash
npm install
npm run dev
```

打开终端中显示的开发服务器地址。已有依赖锁文件时，也可以使用 `npm ci` 进行一致安装。

```bash
npm test         # 五子棋规则、内置 AI、保存校验与模型接口单元测试
npm run build   # 生成 dist/ 静态网站
npm run preview # 本地预览生产构建，需先执行 build
npm run test:e2e # Chromium 中验证实际界面与对弈流程
```

`dist/` 可部署至静态网站托管服务。本项目不包含后端服务。

浏览器测试会使用系统 `/usr/bin/chromium`（若存在）；也可以通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定。没有 Chromium 时先执行 `npx playwright install chromium`。中文字体与依赖一起本地打包，无需访问外部字体服务。

## 怎么玩

- 棋盘为 15 × 15，黑棋先行；横向、纵向或斜向连续 **五颗及以上**同色棋子获胜。采用自由五子棋规则，没有禁手。
- 人机模式提供三个难度的内置 AI，无需 API Key 即可游玩。
- 双人模式由两人在同一设备上轮流落子，不包含联网匹配或远程对战。
- 点击交叉点落子，拖动棋盘调整视角；键盘方向键移动落点，Enter 确认。
- 可使用悔棋和重新开局，尝试不同走法。

## 保存与恢复

棋局会自动保存，也可以手动保存最多 30 局；数据保存在当前浏览器的 `localStorage` 中。在“棋局记录”中可导出当前棋局或导入 JSON 棋局文件。

保存仅对当前浏览器和网站地址生效，不会同步到账号或云端。清理网站数据会删除本地记录；需要长期保存或换设备时，请导出 JSON 文件。

## 接入 AI 模型

在设置中填写 **服务地址、模型名称和 API Key**，使用 OpenAI 兼容的 Chat Completions 接口。例如：

```text
服务地址：https://api.example.com/v1
模型名称：由你的服务商提供
```

也支持填写完整的 `/chat/completions` 地址。请求由浏览器直接发往所填服务；服务端必须允许当前网站来源的 **CORS 跨域请求**，并支持相应模型。远程服务需要 HTTPS，本机 `localhost`、`127.0.0.1` 或 `[::1]` 服务可以使用 HTTP。浏览器仍可能限制 HTTPS 网站访问本机 HTTP 服务。

服务地址和模型名称可以保存。API Key 默认仅保留在当前页面内存中；只有勾选“记住”选项后才会写入浏览器 `localStorage`。本地存储不等于加密保险箱，请只在可信个人设备上记住密钥，不要将密钥写入源代码、棋谱或公开部署文件。

模型需要返回合法的空位坐标。接口认证、网络、超时或落子校验失败时，游戏会提示问题并退回内置 AI，保持对局可继续。自定义模型可能产生调用费用，以服务商规则为准。

接口测试使用模拟响应，覆盖地址处理、请求格式、落子校验、失败响应和取消操作；**没有使用真实凭据验证任何第三方模型服务**。实际连接效果取决于你的接口配置、权限及 CORS 设置。

## 项目结构

```text
src/
  main.js    页面交互、对局流程、设置和保存
  scene.js   Three.js 场景与棋盘渲染
  game.js    五子棋规则、内置 AI 与棋局序列化
  ai.js      OpenAI 兼容模型接口
tests/       Node.js 单元测试
```
