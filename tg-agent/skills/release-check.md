# 发布与交付

1. 确认目标环境、版本、运行用户、工作目录和配置来源，优先使用环境变量引用密钥。
2. 跑对应测试、竞态检测、静态检查和目标平台编译，记录失败原文。
3. 检查压缩包不含 token、API key、聊天记录、上传文件、运行日志和临时构建缓存。
4. 为服务配置超时、重启策略、持久化目录与最低所需文件权限；保留备份和回退步骤。
5. 交付源码、示例配置、启动说明、测试结果和已知限制。

部署和外部写入受当前系统执行模式约束；不要宣称未经实测的服务已经上线。
