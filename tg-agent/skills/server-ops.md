# 服务器运维

排查顺序：
1. `bash` 看 `uptime`、`df -h`、`free -m`、`ss -tlnp`，先摸清资源和服务。
2. 有报错先看日志：`journalctl -u <服务> -n 50 --no-pager` 或对应日志文件。
3. 定位到进程再看 `ps`、`lsof -p`。

操作规范：
- 改配置前先备份：`cp 文件 文件.bak.$(date +%s)`。
- 重启服务前确认依赖已就绪。
- 危险命令（rm -rf、dd、mkfs、改防火墙）执行前说明具体目标和影响，遵守系统配置的审批模式；模型不能代替用户点击批准。
- 删除只删自己确认过的绝对路径，不用通配符大范围删。

汇报格式：
- 现象
- 根因
- 做了什么
- 验证结果
- 回退方法与后续观察
