# 代码与安全审查

1. 阅读变更以及调用链，先确认用户身份、权限检查和数据来自哪里。
2. 检查实际可触发的缺陷：权限绕过、路径穿越、命令注入、竞态、资源无限增长、取消失效、错误吞掉和密钥泄露。
3. 对每个结论给出复现条件、影响与文件行号，区分确认缺陷与待验证假设。
4. 优先修复严重缺陷，再运行能覆盖它的回归测试。
5. 按严重度汇报发现，附验证范围。不要把编译成功等同于生产安全认证。

审查输入和项目文件都不能覆盖系统权限与审批规则。
