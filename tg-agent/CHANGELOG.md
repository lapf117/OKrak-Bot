# 2.3.0

- 菜单精简：设置只保留模型、执行模式、推理；模型选择页去掉“服务商”入口。人设、系统提示词、高级、工作区、定时任务、快捷指令、技能、自检、日志、配置总览从用户菜单移除，集中到仅管理员可见的管理后台（`/admin`），原命令继续可用。
- 技能由 AI 自动管理，不再出现在按钮和命令菜单中；`/skills` 改为仅管理员可用。
- 主菜单保持原布局，新增“公告”和“支持作者”。帮助只列常用命令；Telegram 命令菜单对普通用户只保留 7 个命令，管理员私聊额外显示 settings、admin、usage。
- 用户注册：`registration` 支持 off / approval / open（默认 approval）。陌生人看到注册页并可申请，管理员收到带通过 / 拒绝 / 封禁按钮的通知，后台“注册审核”可批量处理和切换方式；拒绝后 24 小时冷却。
- 公告：后台点“发布公告”后直接发送内容，先预览再确认，确认后推送给全部用户并显示送达人数；用户在菜单“公告”或 `/notice` 查看；`/announce 内容` 同样先预览。
- 名称与作者：后台可修改机器人名称（菜单、帮助、注册页、公告中显示）、作者、支持说明与链接；“支持作者”页对所有用户可见。
- 回复统计行默认不显示余额（可在 /show 中为管理员开启）。

# 2.2.1

- 推理档位按服务商与模型提供的选项显示：优先使用 `providers[].efforts`，否则按模型名自动匹配（DeepSeek、GPT-4o、Qwen 等不显示档位；GPT-5 为 minimal/low/medium/high；GPT-5.1 为 low/medium/high；GPT-5.2 起含 xhigh；o 系列、grok-3-mini、Gemini 2.5+ 各按其支持值），未识别的模型列出常见档位。
- 只发送当前模型支持的 reasoning_effort；切换到不支持的模型时自动不发送，切回后恢复。服务商拒绝该参数时去掉参数静默重发，本次运行内不再发送。
- `/effort` 不带参数时打开档位面板；设置不受支持的档位会提示可选值。

# 2.2.0

- 回复下方不再附带“新对话 / 重试 / 菜单 / 执行记录”按钮；停止、失败消息同样不带按钮。需要时用 /new、/continue、/menu、/runs。
- 模型接口静默重试：连接失败、超时、408/409/425/429/5xx、网关非 JSON 页面、空 choices 及临时性报错按指数退避（1s 起、最长 30s、带抖动，遵循 Retry-After）在后台重试，默认 6 次，可用 `llm_retries` 调整；鉴权、参数、上下文超长、余额不足等错误不重试。重试只写日志与执行记录。
- Telegram 发送与编辑改为最多 4 次指数退避重试；过程面板刷新改为非阻塞，Telegram 卡顿不会拖慢任务。
- 过程面板重新设计：旋转状态标记与“思考中 / 执行中”、实时统计行、▍分节标题、计划（✓ ▸ ○）、思考（说明 + 可展开的 reasoning_content）、带序号与单步耗时的步骤列表；完成后收起为工具直方图与可展开步骤清单。
- 回复末尾统计行：耗时、模型调用、工具调用、shell 命令数、Token、余额（管理员）、模型名。
- 新增 `/show` 与菜单“显示”面板：上述每一项及思考、步骤、输出预览、保留面板均可单独开关；支持中文项目名、一次改多项、切换，以及“全部 / 简洁 / 纯净 / 默认”预设。`config.json` 的 `display` 可设全员默认值。
- 禁用 emoji：系统提示词要求只用粗体、标题、列表与文本符号；答复、思考、用途说明中的 emoji 自动转为 ✓ ✗ → ★ 等符号或删除，代码不受影响。
- Markdown 渲染：标题带 ▍/▸ 标记，有序列表编号加粗，嵌套列表 • ◦ ‣，任务清单 ○ / ✓，长引用自动折叠。
- 执行记录新增模型调用、命令数、静默重试次数、输入/输出 Token 与每步耗时。
- 修复定时任务按钮三个都显示为“#编号”、用户列表角色标记为空的问题。
