# 2.0.0

- 简化 Telegram 主菜单；高级配置、审批、模型、工作区、自动化与权限集中到二级设置。
- 增加人工确认、自动执行和只读模式；审批绑定用户、私聊、工具与完整参数。
- 修复模型绕过工具 schema 的权限漏洞，以及子智能体提升到主人身份与无限递归的问题。
- 修复停止按钮只设置标记而不取消执行；增加 HTTP 取消、命令进程组终止、任务与子任务共享预算。
- 增加私密会话持久化、完整轮次裁剪、预算耗尽总结，成功/失败/取消均记录。
- 修复纯语音、音频、动画与视频消息漏处理，修复 Telegram 长回复切片和 UTF-16 长度处理。
- 配置改为线程安全快照与原子保存，支持环境变量密钥引用并避免保存时展开密钥。
- 增强文件读取、精确编辑、备份和多次撤销，修复 Git diff 目录及搜索参数注入问题。
- 技能兼容 SKILL.md 与项目目录，修复原版扫描错用全局技能目录；增加自动匹配和固定哈希可信目录安装。
- 增加私聊限定、朋友工作区路径检查、管理员文件回传和严格 SSH 主机校验。
- 定时任务以创建者身份执行；无法确定创建者的旧任务停用，触发前重新检查权限。
- 补齐配置示例、部署模板、容器、CI、单元测试与源码参考说明。
