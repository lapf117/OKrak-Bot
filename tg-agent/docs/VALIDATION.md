## 测试覆盖的实际行为

- 配置深拷贝、原子保存、环境变量密钥引用保留、非法配置拒绝；旧无创建者定时任务停用。
- 模拟模型执行完整 write → edit → read 工具链，文件结果与持久化历史均正确。
- 执行预算到达后只做无工具总结；中断工具批次补齐未完成结果，历史可继续发送。
- 模型 HTTP 401 不重试，503 按退避重试；取消请求不发到服务端；权限撤销后拒绝请求。
- 只读模式无法通过直接伪造工具调用写文件或执行 shell；子任务不能隐式取得主人身份。
- 人工审批绑定任务发起者与私聊，一次性消费；过长参数拒绝，不能隐藏尾部命令。
- 任务配置与密钥冻结后，设置改变仍能脱敏旧密钥；停机时拒绝迟到的新任务。
- 16 个普通任务占满时，下一条任务不会阻塞轮询；审批仍可处理，停止即使控制并发已满也能本地取消。
- Shell 取消会关闭子进程占有的管道；输出受限；超大文件编辑不改动原文；多次撤销逐版本恢复。
- 朋友的目录穿越、符号链接和自动项目说明读取不能绕过工作区边界；只读 Git schema 限四类查询。
- 技能优先级、SKILL.md、符号链接、大小与 UTF-8 限制、YAML 多行描述、自动匹配；HTTPS 来源白名单、SHA256、错误摘要保留旧版本与重定向拦截。
- Telegram UTF-16 长消息分片与完整发送；文件回传路径、私密文件及符号链接限制；带 @bot 的命令参数解析。
